# EP○○. (작품명) (연도) · 노스포 (영화/애니/드라마/예능) 리뷰

| 항목 | 내용 |
|---|---|
| 형식 | 유튜브 쇼츠 · 9:16 · 약 55초 (대사 전체 250~300자) |
| 작품 정보 | 감독 또는 방송사 · 연도 · 한 줄 특징 |
| ⚠️ 업로드 전 | 넷파일에서 이 작품이 정식(제휴) 콘텐츠로 검색되는지 확인 |

작성 규칙
- 대사는 애교 있는 존댓말로 씁니다 ("~거든요?", "진짜요?", "저랑 같이 봐요").
- 결말, 반전, 정체 공개는 말하지 않습니다.
- 작품 정보(감독, 연도, 수상, 배경)는 사실만 씁니다. 확실하지 않으면 빼세요.
- 포스터, 스틸컷, 예고편, OST는 쓰지 않고 단색이나 일반 스톡 이미지로 분위기만 냅니다.
- 선정적인 표현은 쓰지 않습니다.

## 1. HeyGen 씬별 대본

### 씬 1 · 훅 (3~5초)
- 배경:
- 화면 텍스트: **(시청자에게 던지는 질문, 15자 안팎)**
```
(공감 질문 한 문장)
```

### 씬 2 · 소개 (10~12초)
- 배경:
- 화면 텍스트: **(작품명) (연도) · (감독/방송사)**
```
오늘은 (감독/방송사)의 (작품명)이에요. (주인공)이 (상황)하면서 (이야기가 시작되는 지점)하거든요.
```

### 씬 3 · 포인트 ① (10초)
- 배경:
- 화면 텍스트: **POINT 1 · (눈여겨볼 장면)**
```
(볼 때 주목할 장면이나 연출 + 왜 좋은지)
```

### 씬 4 · 포인트 ② (10초)
- 배경:
- 화면 텍스트: **POINT 2 · (감정 포인트)** (스포 금지 🤫)
```
(분위기가 바뀌는 지점이나 감정 포인트). 더 말하면 스포라서, 여기까지만 할게요.
```

### 씬 5 · CTA (10~12초)
- 배경: 따뜻한 조명의 거실 (아바타 기본 배경)
- 화면 텍스트: **넷파일 첫 가입 2,000코인** (작게: 2,000원 상당 · 링크는 프로필)
```
궁금해졌죠? (작품명), 넷파일에서 볼 수 있어요. 처음 가입하면 2,000코인 주니까, 오늘 밤에 저랑 같이 봐요. 링크는 프로필에 있어요! (댓글 유도 질문)
```
