넷파일 서비스 설명 없이, 리뷰 마지막에 "넷파일에서 같이 봐요 + 첫 가입 2,000코인" 한마디로 자연스럽게 가입을 유도합니다.

## 1. 채널 컨셉

- **포맷**: 유튜브 쇼츠, 세로 9:16, 50~60초, 노스포 리뷰
- **채널명 예시**: `유나의 오늘 뭐 봄?`, `유나 1분 리뷰`
- **업로드**: 주 3회 (영화 → 애니 → 방송 순환), 저녁 퇴근·하교 시간대 예약 공개
- **가입 링크 위치는 채널 프로필 링크**
  - 쇼츠는 설명란·댓글에 넣은 링크가 **눌리지 않습니다.** 그래서 대사도 "링크는 프로필에 있어요"로 통일했습니다.
  - YouTube 스튜디오 → 맞춤설정 → 프로필(기본 정보) → **링크**에 넷파일 가입 페이지를 등록하세요.
  - 링크는 **넷파일 가입·이벤트 페이지로 바로** 연결합니다. 성인물 사이트를 거치게 하면 유튜브 외부 링크 정책 위반으로 영상이 삭제되거나 경고를 받을 수 있습니다.

## 2. 페르소나 '유나'

| 항목 | 설정 |
|---|---|
| 나이·성별 | 20대 중반 여성 |
| 말투 | 애교 있는 존댓말 + 살짝 설레게 하는 한마디. "~거든요?", "진짜요?", "저랑 같이 봐요", "약속!" |
| 목소리 | 밝고 부드러운 톤의 한국어 여성 음성, 속도 1.05~1.1 |
| 외형 | 편안한 니트나 블라우스, 따뜻한 조명의 거실이나 방 배경 |

**'섹시한' 느낌은 차분하고 부드러운 음색과 자신감 있는 말투로만** 냅니다. 선정적인 멘트나 노출 의상은 넣지 않았습니다.
- HeyGen 콘텐츠 정책상 선정적인 영상은 생성이 거절되거나 계정이 제재될 수 있습니다.
- 유튜브에서 연령 제한이 걸리면 쇼츠 피드 노출이 크게 줄어듭니다.
- 웹하드 홍보와 선정적 화법이 겹치면 성인물 홍보로 신고될 위험이 큽니다.

**HeyGen에서 '유나' 아바타 만들기 (최초 1회)**
- 사진 아바타를 AI로 생성하는 메뉴(Photo Avatar → AI로 생성)에서 아래 프롬프트를 쓰면, 다른 채널과 겹치지 않는 전용 얼굴이 생깁니다. 메뉴 이름은 HeyGen 업데이트에 따라 다를 수 있습니다.
  ```
  Korean woman in her mid-20s, warm playful smile, shoulder-length brown hair,
  cream knit sweater, sitting in a cozy living room with soft warm lighting,
  upper body, facing the camera, natural makeup, photorealistic
  ```
- 세련된 느낌을 원하면 의상을 `black knit top, subtle makeup` 정도로 바꿉니다.
- 같은 얼굴로 의상만 다른 버전을 2~3개 만들어 두면, 장르별로 바꿔 써서 덜 지루해 보입니다.
- 스톡 아바타를 쓸 때는 20대 여성 아바타 하나를 정해 **모든 에피소드에 같은 아바타**를 씁니다.
- 실존 인물(연예인, 지인) 얼굴은 본인 동의 없이 쓰면 안 됩니다.

## 3. 에피소드 공식 (5씬, 약 55초)

| 씬 | 길이 | 역할 | 예시 |
|---|---|---|---|
| 1 훅 | 3~5초 | 질문으로 붙잡기 | "자고 일어났는데 남의 몸이라면, 어떡할 거예요?" |
| 2 소개 | 10~12초 | 감독·작품명 + 설정 한 줄 | "오늘은 ○○ 감독의 ○○이에요." |
| 3 포인트① | 10초 | 볼 때 눈여겨볼 장면 (노스포) | "계단을 꼭 잘 봐 주세요." |
| 4 포인트② | 10초 | 감정 포인트 + "스포라서 여기까지" | "마지막엔 휴지 꼭 옆에 두세요." |
| 5 CTA | 10~12초 | 작품명 + 넷파일 + 2,000코인 + 같이 봐요 + 프로필 링크 + 댓글 유도 | (아래 고정 문구) |

**CTA 고정 문구** (작품명만 바꿔서 매 회 똑같이)
```
궁금해졌죠? (작품명), 넷파일에서 볼 수 있어요. 처음 가입하면 2,000코인 주니까, 오늘 밤에 저랑 같이 봐요. 링크는 프로필에 있어요!
```

## 4. HeyGen 웹 제작 순서 (에피소드마다)

1. **새 영상**을 만들고 화면 비율을 **세로 9:16**으로 고릅니다.
2. 씬을 5개 만들고, 에피소드 파일의 **대사 블록을 씬마다 하나씩** 붙여 넣습니다.
3. 모든 씬에 같은 아바타('유나')와 **같은 음성**을 지정합니다.
   - 음성은 씬 1 대사로 한국어 여성 음성 3~4개를 미리 들어 보고 고릅니다.
   - 감정이나 톤 옵션이 있는 음성이면 밝고 친근한 쪽으로 맞춥니다.
4. **배경**: 에피소드 파일의 배경 메모대로 단색이나 HeyGen 스톡 이미지를 넣습니다.
   - ⚠️ 영화 포스터, 스틸컷, 예고편 장면, OST는 쓰지 않습니다. 저작권 신고(Content ID)로 수익이 막히거나 영상이 차단됩니다.
5. **화면 텍스트**: 씬마다 '화면 텍스트'를 크게 얹습니다.
   - **화면 아래쪽 20%와 오른쪽 끝은 비워 두세요.** 쇼츠의 제목, 좋아요, 댓글 버튼이 그 위를 덮습니다.
6. 화면 위쪽 구석에 작게 **"AI 아바타"** 라고 표시합니다.
7. **자막(캡션)을 켜고** 렌더링한 뒤 MP4를 내려받습니다. 요금제가 지원하면 1080p로 받습니다.

> 💡 숫자나 영어를 이상하게 읽으면 한글로 바꿔 쓰세요. (예: `2,000코인` → `이천 코인`, `1988` → `천구백팔십팔`)
> 💡 숨 쉬는 지점은 쉼표로 조절합니다. 말이 너무 빠르면 쉼표를 하나 더 넣으세요.

## 5. 유튜브 업로드 순서

1. 유튜브 앱이나 스튜디오에서 MP4를 업로드합니다. 세로 영상이고 3분 이하면 자동으로 쇼츠가 됩니다.
2. 에피소드 파일의 **제목, 설명, 해시태그**를 붙여 넣습니다.
3. 시청자층은 **"아동용이 아님"** 으로 고릅니다.
4. 세부정보에서 아래 두 가지를 설정합니다.
   - 넷파일로부터 대가를 받거나 제휴 관계라면 **"유료 프로모션 포함"** 을 체크합니다.
   - **"변경되거나 합성된 콘텐츠"** 는 **예**로 고릅니다. 사실적인 AI 아바타와 AI 음성을 쓰기 때문입니다.
5. 공개 시간을 예약하고, 공개 직후 **고정 댓글**을 달고 고정합니다.
6. 첫 1시간 동안 달린 댓글에 답글을 달아 줍니다 (초반 반응이 노출에 도움이 됩니다).

## 6. 업로드 전 체크리스트

- [ ] **해당 작품이 넷파일에 정식(제휴) 콘텐츠로 있는지 검색해서 확인했다.** 없는 작품에 "넷파일에서 볼 수 있어요"라고 하면 허위 광고입니다.
- [ ] 가입 혜택 문구가 넷파일 현재 공지와 같다 (첫 가입 2,000코인, 2,000원 상당)
- [ ] 설명란 첫 줄에 `[광고]` 표기가 있다 (추천·보증 심사지침)
- [ ] 영상 안에 "AI 아바타" 표시가 있고, 유튜브 합성 콘텐츠 항목을 '예'로 골랐다
- [ ] 포스터, 스틸컷, 예고편, OST를 쓰지 않았다
- [ ] 결말이나 반전 스포일러가 없다
- [ ] 선정적인 표현이나 의상이 없다
- [ ] 채널 프로필 링크가 넷파일 가입 페이지로 바로 연결된다
- [ ] 매 회 리뷰 포인트가 다르다. 같은 틀만 반복하는 AI 영상은 유튜브가 수익화를 제외하거나 노출을 줄일 수 있습니다.
