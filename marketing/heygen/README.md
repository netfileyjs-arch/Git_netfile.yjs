# 🎬 HeyGen으로 만드는 넷파일 회원가입 유도 영상

AI 아바타가 말하는 짧은 영상으로 **넷파일 신규 가입**을 늘리기 위한 기획안과 제작 도구입니다.

| 파일 | 용도 |
|------|------|
| `README.md` | 기획안, HeyGen 제작 순서, 업로드 전 체크리스트 |
| `videos.json` | 영상 5편의 대본·씬·연출 메모 (웹 제작과 API 제작에 같이 씀) |
| `heygen_generate.py` | HeyGen API로 `videos.json`을 한 번에 렌더링하는 스크립트 (선택) |

---

## 1. 기획 방향

- **목표**: 영상 조회 → 링크 클릭 → 회원가입
- **타깃**: 드라마·영화·예능을 자주 찾아보는 20~40대, 숏폼 위주 시청자
- **핵심 메시지 3가지**
  1. *볼 거 찾는 시간 낭비 끝*: 보고 싶은 콘텐츠를 한 곳에서 검색
  2. *지금 가입하면 혜택*: 실제 진행 중인 가입 이벤트 (`{{가입혜택}}`)
  3. *가입은 1분*: 진입 장벽을 낮추는 튜토리얼
- **공통 원칙**
  - 첫 2초 안에 공감 질문으로 훅을 건다 (숏폼은 3초 이탈이 가장 큼)
  - 대부분 소리 없이 보므로 **자막은 항상 켬**
  - 마지막 씬은 늘 같은 CTA 화면 (버튼 모양, 색, 문구 통일)
  - 혜택·조건은 **실제 이벤트 내용과 똑같이**, 조건은 작은 자막으로 표시

## 2. 영상 기획안 (4가지 컨셉, 총 5편)

### A. 숏폼 훅: "주말에 뭐 보지?" ⭐ 먼저 만들 것
- **9:16 · 15~20초** · 쇼츠 / 릴스 / 틱톡
- 흐름: 공감 질문 → 넷파일로 해결 → 가입 혜택 CTA
- 대본:
  1. "주말에 볼 거 찾다가, 한 시간 날린 사람?"
  2. "드라마, 영화, 예능까지. 넷파일 하나면 보고 싶은 걸 검색 한 번에 찾을 수 있어요."
  3. "지금 신규 가입하면 `{{가입혜택}}`. 프로필 링크에서 1분이면 가입 끝!"
- 훅 A/B 테스트용 대체 첫 문장 (`hook_variants`):
  - "보고 싶은 드라마, 어디서 봐야 할지 모르겠다면?"
  - "오늘 밤 정주행할 거 아직 못 골랐죠?"

### B. 혜택 직구형: "가입만 해도" ⭐ 먼저 만들 것
- **9:16 · 20~25초** · 릴스 / 쇼츠 / 유료 광고 소재
- 이벤트가 있을 때 가장 전환이 빠른 형태. 혜택 문구를 화면 가운데 크게.
- 대본: "잠깐! 아직 넷파일 회원 아니세요?" → "지금 가입하면, `{{가입혜택}}`." → "받은 혜택으로 보고 싶었던 영화나 드라마를 부담 없이 먼저 시작해 보세요." → "이벤트는 `{{이벤트기간}}`까지예요. 프로필 링크에서 지금 바로 받아 가세요."
- 상시 혜택이면 마지막 씬의 기간 문장을 빼세요. 없는 마감일로 급하게 만드는 표현은 쓰지 않습니다.

### C. 가입 튜토리얼: "1분이면 끝"
- **16:9 · 40~50초** · 유튜브 본편 / 랜딩페이지 / 블로그 삽입
- **배경에 실제 가입 화면 녹화본**을 깔고, 아바타는 원형(`circle`)으로 구석에 배치
- 대본: 세 단계(회원가입 버튼 → 아이디·비밀번호·본인 인증 → 가입 혜택 확인) 안내 후 "가입 링크는 설명란에"
- ⚠️ 2·3번 씬은 **실제 가입 절차를 보고 문장을 맞춰** 주세요. 녹화 시 개인정보는 모자이크.

### D. 공감 시리즈: "이럴 때 넷파일" (#1 출근길, #2 주말 정주행)
- **9:16 · 각 15초** · 주 1회 연재
- 같은 아바타, 같은 상단 자막("이럴 때 넷파일 #N"), 같은 CTA로 시리즈처럼 보이게
- 반응 좋은 상황을 골라 #3, #4로 확장 (예: 명절 연휴, 비 오는 날, 시험 끝난 날)

### 추천 진행 순서
1. **A, B**를 9:16으로 먼저 제작 → 1~2주 게시하면서 훅 3종 비교
2. 3초 시청 유지율이 가장 높은 훅으로 **D 시리즈** 연재
3. **C**는 랜딩페이지·유튜브 설명란에 고정해 두고 계속 재활용

## 3. HeyGen 웹에서 만드는 법 (코딩 없이)

1. **대본 확정**: `videos.json`의 `{{가입혜택}}`, `{{이벤트기간}}`을 넷파일 실제 이벤트 내용으로 바꿉니다.
2. **새 영상 만들기**: HeyGen에서 아바타 영상(AI Studio)을 새로 만들고 화면 비율을 고릅니다 (A·B·D는 9:16, C는 16:9).
3. **아바타 선택**: 스톡 아바타 중 친근한 20~30대 느낌을 고르고, 모든 편에 **같은 아바타**를 씁니다 (시리즈 인지도).
   - 본인 얼굴로 아바타를 만들 때는 본인 촬영본만 사용. 타인·연예인 얼굴은 동의 없이 쓰면 안 됩니다.
4. **음성**: 언어를 Korean으로 걸러 자연스러운 한국어 음성을 고릅니다. 숏폼은 속도 1.05~1.1 정도가 답답하지 않습니다.
5. **씬 입력**: `videos.json`의 `scenes`를 한 씬에 하나씩 붙여 넣습니다. 쉼표·마침표 위치가 숨 쉬는 지점이 됩니다.
6. **연출**: 각 씬의 `overlay` 메모대로 텍스트, 로고, CTA 버튼, 배경(브랜드 색 또는 화면 녹화)을 얹습니다.
7. **자막 켜기**, 하단에 작게 "AI 아바타로 제작된 광고" 문구를 넣습니다 (아래 체크리스트 참고).
8. 미리보기 후 렌더링 → MP4 다운로드.

> 💡 HeyGen의 프롬프트형 기능(Video Agent 등)을 쓴다면 아래처럼 지시하면 됩니다.
>
> "넷파일 웹하드 신규 회원가입을 유도하는 9:16 세로 숏폼 광고를 만들어줘. 길이 18초, 한국어, 20대 후반 친근한 아바타 한 명.
> 대본은 정확히 다음 3문장만 사용: (A안 대본 붙여넣기). 큰 한국어 자막, 마지막 3초는 '지금 가입하기' 버튼 화면.
> 특정 영화·드라마 장면이나 포스터는 넣지 말 것. 하단에 'AI 아바타로 제작된 광고' 표기."

## 4. API로 한꺼번에 만드는 법 (선택)

여러 편을 반복 생성하거나 훅 A/B 버전을 많이 뽑을 때 씁니다. HeyGen API 키가 필요하고, API 사용량은 요금제/크레딧 조건을 따릅니다.

```bash
cd marketing/heygen

# 1) API 키 지정
set HEYGEN_API_KEY=발급받은키              # Windows cmd
$env:HEYGEN_API_KEY="발급받은키"           # Windows PowerShell
export HEYGEN_API_KEY=발급받은키           # macOS / Linux

# 2) 쓸 음성과 아바타 id 찾기 → videos.json의 defaults에 입력
python heygen_generate.py voices --lang Korean
python heygen_generate.py avatars --search Daisy

# 3) 요청 내용 미리 보기 (API 호출 없음)
python heygen_generate.py render --dry-run

# 4) 워터마크 테스트 영상으로 먼저 확인
python heygen_generate.py render --only A_hook_weekend --test

# 5) 최종 렌더링 → output/ 에 MP4 저장 (자막 입힌 버전은 *_caption.mp4)
python heygen_generate.py render --only A_hook_weekend B_benefit
```

- `videos.json`에 `TODO` 값이 남아 있으면 렌더링을 거부합니다. 확인되지 않은 혜택 문구가 광고로 나가는 것을 막기 위해서입니다.
- 요금제가 1080p를 지원하지 않으면 `--resolution 720`을 붙이세요.
- 생성 요청만 하고 나중에 받으려면 `--no-wait` 후 `python heygen_generate.py status <video_id> --download`.
- API는 아바타가 말하는 부분과 자막까지만 만듭니다. CTA 버튼·로고·화면 녹화는 HeyGen 웹 편집기나 CapCut 같은 편집 툴에서 얹으세요.
- HeyGen API는 바뀔 수 있으니, 오류가 나면 HeyGen 공식 API 문서의 `/v2/video/generate`, `/v1/video_status.get` 항목과 비교해 보세요.

## 5. 성과 측정

- 영상마다 **가입 링크를 따로** 만듭니다 (넷파일 제휴/추천 코드 또는 UTM, 예: `utm_source=shorts&utm_content=A_hook1`).
- 볼 지표: **3초 시청 유지율**(훅 품질) → **링크 클릭률**(CTA 품질) → **가입 전환율**(혜택·랜딩 품질)
- 2주마다 성과가 가장 낮은 훅/대본을 교체합니다.

## 6. 업로드 전 체크리스트

- [ ] **혜택·기간·조건이 넷파일 공지와 정확히 일치**하는가 (과장·허위 표현은 표시광고법 위반 소지)
- [ ] 제휴 수수료를 받는 링크라면 **"광고" / "유료 광고 포함"** 표시를 했는가 (추천·보증 심사지침)
- [ ] **AI 생성 표시**: 영상 하단 "AI 아바타로 제작된 광고" 문구 + 업로드 시 플랫폼의 AI 생성 콘텐츠 표시 항목 체크.
      인공지능기본법(2026. 1. 22. 시행)의 생성형 AI 표시 의무가 광고주에게도 직접 적용되는지는 해석이 갈리지만, 표시해 두는 편이 안전합니다.
- [ ] **선정적·성인 콘텐츠를 연상시키는 표현 없음**: HeyGen 콘텐츠 정책 위반으로 생성 거절이나 계정 제재를 받을 수 있고, 청소년 노출 플랫폼 광고 정책에도 걸립니다. 영상은 일반 콘텐츠 이용 장면만 다룹니다.
- [ ] **특정 영화·드라마 포스터, 장면, 음악을 쓰지 않음** (권리 없음). "무료로 영화 다운" 같은 불법 공유를 연상시키는 문구도 쓰지 않음.
- [ ] 넷파일 **로고·상표 사용**이 제휴 정책상 허용되는 범위인가
- [ ] 튜토리얼 화면 녹화에 개인정보(아이디, 전화번호 등)가 보이지 않는가
