# 파일명 키워드 필터

파일명 목록에서 지정한 키워드가 들어간 파일명을 골라내 엑셀로 저장합니다.
키워드는 **한글 ↔ 영문으로 서로 번역**해서 함께 검색합니다 (예: `몰카` → `hidden camera`, `spycam` … / `incest` → `근친`, `근친상간` …).

## 파일 구성

| 파일 | 설명 |
|---|---|
| `파일명_키워드_필터.html` | **단독 실행 웹페이지** — 더블클릭으로 바로 사용 |
| `standalone_template.html`, `build_standalone.py` | 위 HTML 을 다시 만드는 원본과 스크립트 |
| `web_app.py` | 웹 서버판 (http://localhost:5050) |
| `filter_files.py` | 명령줄 프로그램 |
| `filter_core.py` | 검색·번역·엑셀 저장 로직 (웹/명령줄 공용) |
| `dictionary.txt` | 한글 ↔ 영문 번역 사전 (직접 수정 가능) |
| `keywords.txt` | 기본 키워드 목록 |
| `filenames.txt` | 예시 파일명 목록 |
| `키워드_필터_결과.xlsx` | 예시 목록을 돌린 결과 |

## 가장 쉬운 방법: HTML 파일 하나로 사용 (설치 필요 없음)

`파일명_키워드_필터.html` 을 내려받아 **더블클릭**하면 브라우저(크롬/엣지/웨일 등)에서 바로 열립니다.

- Python, 인터넷 연결 모두 필요 없음. 검색과 엑셀 생성까지 전부 브라우저 안에서 처리
- 파일명/키워드를 어디로도 전송하지 않음
- 입력한 키워드와 편집한 사전은 그 브라우저에 기억됨
- 사전을 다른 PC로 옮길 때는 "사전 파일로 내보내기" → 다른 PC에서 "사전 파일 불러오기"

`dictionary.txt` 나 `keywords.txt` 의 기본값을 바꾼 뒤 HTML 에 반영하려면:

```bash
python build_standalone.py
```

## 설치 (아래 웹 서버판/명령줄판을 쓸 때만)

```bash
pip install flask openpyxl
```

## 웹 서버판으로 사용

```bash
cd filename_filter
python web_app.py
```

브라우저에서 http://localhost:5050 접속.

1. **파일명 목록**: 붙여넣기, `.txt` 목록 파일 불러오기, 파일/폴더 선택(이름만 읽음), 끌어다 놓기 중 편한 방법으로 추가
2. **키워드**: `/`, 줄바꿈, 쉼표로 구분해서 입력 (입력한 키워드는 브라우저에 기억됨)
3. **키워드 포함 파일 골라내기** 클릭
4. 결과에서 잘못 걸린 파일은 체크 해제 → **엑셀 다운로드**

"번역 사전 편집" 버튼으로 사전을 바로 고치고 저장할 수 있습니다.

## 명령줄로 사용

```bash
python filter_files.py 파일목록.txt 키워드.txt -o 결과.xlsx
python filter_files.py D:\동영상 키워드.txt -r        # 폴더 안 파일명을 직접 읽기 (-r: 하위 폴더 포함)
python filter_files.py 파일목록.txt 키워드.txt --no-translate   # 번역 없이 원문 키워드만
```

## 엑셀 결과

| 시트 | 내용 |
|---|---|
| 키워드 포함 (제거 대상) | 걸린 파일명, 매칭된 키워드, 실제 걸린 단어, 원문/번역 구분 |
| 나머지 파일 | 키워드가 없는 파일명 |
| 키워드 번역표 | 키워드별로 함께 검색한 번역어와 걸린 파일 수 |
| 요약 | 전체/제거 대상/나머지 개수 |

## 매칭 규칙

- 대소문자 무시, 전각문자(`ＳＥＸ`)는 보통 문자로 바꿔서 비교
- 키워드가 파일명 안에 **포함**되면 걸림 (`nana` → `Nanami`, `teen` → `Thirteenth` 도 걸림. 이런 건 결과 화면에서 체크 해제)
- 영문 앞에 `=` 를 붙이면 단어 단위로만 검색 (`=cum` → `Cum.In.Throat` 은 걸리고 `document` 는 안 걸림)
- 띄어쓰기가 있는 영문은 공백·점·밑줄·하이픈이 있든 붙어 있든 매칭 (`hidden camera` → `Hidden.Camera`, `HiddenCamera`)
- 나이 표기는 사전 없이 자동 변환 (`15세` ↔ `15살` ↔ `15歲` ↔ `15yo` ↔ `15 years old`)

## 번역 사전 (`dictionary.txt`)

```
한글1, 한글2 = english1, english2
```

왼쪽 단어로 찾으면 오른쪽 영문이, 오른쪽 영문으로 찾으면 왼쪽 한글이 함께 검색됩니다.
사전에 없는 키워드는 원문만 검색되므로, 필요한 번역은 사전에 한 줄씩 추가하세요.
사람 이름(인명)은 번역하지 않았습니다.
